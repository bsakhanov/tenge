# Цифровой тенге в Казахстане: доклад-исследование

Рабочий репозиторий регулярного исследования проекта «цифровой тенге» (РК): доклад, реестры фактов, методология, список наблюдения и сборка. Цель: каждые полгода обновлять доклад и выпускать новые, более свежие редакции, не теряя связи с предыдущими.

**Текущий выпуск:** редакция **1.1.1** — аналитическая (шесть томов) и публичная (научно-популярная, для the-tenge.kz) на одном реестре; срез данных 31 октября 2026 года. Файлы: `editions/1.1.1/`; на странице релиза `v1.1.1` — всё вместе. Прежние выпуски: `editions/1.1/`, `editions/1.0.1/`, `editions/1.0/`.

## Что внутри

```
edition.yml               паспорт редакции (номер, дата, срез, вид выпуска)
CHANGELOG.md              что менялось от редакции к редакции
report/src/               аналитический доклад в Markdown: front, vol1–vol6, appendix
report/public/            публичная редакция: chapters/, data/*.json, figures/, template/ (HTML, CSS, JS), sources.md
registry/                 реестры как данные: facts.csv, discrepancies.csv, gaps.csv
watch/                    список наблюдения, поисковые запросы, временной ряд показателей
sources/                  манифест источников (файлы в git не кладутся); verifications/ — отчёты внешней сверки реестра
methodology/              протокол обновления, внешняя сверка, языковой прогон (Редколлегия), иерархия источников, типографика, уроки, бэклог
tools/                    Редколлегия и редакторы (ставит scripts/redkollegiya_setup.sh; вне git)
scripts/                  сборка, проверки, линтер, манифест, извлечение текста
editions/<X.Y>/           выпущенные docx и PDF, снимок реестров, SHA256SUMS
.github/                  шаблоны задач и автоматизация
```

## Быстрый старт

Требуется: Python 3.10+, pandoc, LibreOffice (`soffice`), poppler (`pdfinfo`, `pdftotext`), шрифты Times New Roman и Arial (либо метрически совместимые Liberation); для публичной редакции дополнительно matplotlib и Pillow, для автотеста — Playwright.

```bash
pip install -r requirements.txt
make check     # целостность кодов Ф-/Р-/М-/R-, ссылки, счётчики (аналитическая дорожка)
make lint      # типографика, язык и кальки из каталога (предупреждения)
make redkollegiya   # поставить Редколлегию и редакторов в tools/ (один раз)
make guard     # страж языкового прохода: факты и разметка не задеты
make typo      # типографика Мильчиным с защитой разметки (последним шагом)
make build     # аналитическая редакция: docx + PDF в dist/
make charts    # иллюстрации публичной редакции (matplotlib)
make public    # публичная редакция: HTML, docx, PDF, метаданные для Joomla
make test-public   # автотест интерактивности (pip install -r requirements-dev.txt; playwright install chromium)
make snapshot  # зафиксировать выпуск в editions/<X.Y>/
```

Правки вносятся только в `report/src/*.md` и `registry/*.csv`. Таблицы приложений А–В и счётчики в титуле и резюме собираются автоматически; руками их править не нужно.

## Как выпускать новую редакцию

Коротко: открыть задачу «Цикл обновления» → собрать новое по списку наблюдения → пройти реестр и пометить устаревшее (`superseded`) → проверить новые тезисы по протоколу → внешняя сверка реестра (`methodology/external-verification.md`) → править тома → языковой прогон Редколлегией (`methodology/language-pass.md`) → `make build` → обновить `edition.yml` и `CHANGELOG.md` → `make snapshot` → тег `vX.Y`. Подробно: `methodology/update-protocol.md`.

Ритм: весна (срез 30 апреля) — X.1; осень (срез 31 октября) — X.0; внеочередной выпуск — при триггерах из протокола.

## Принципы

1. Факты не удаляются; устаревший факт заменяется ссылкой на новый.
2. У каждого числа есть источник и дата среза; непроверенное помечается и выносится в реестр расхождений или белых пятен.
3. Оценки автора подписаны как оценки.
4. Внешние материалы (черновики, статьи, записки партнёров) проверяются по первоисточнику; вердикт записывается.
5. Данные оператора принимаются как его заявления, а не как независимый аудит.

Авторство: аналитическая редакция — Саханов Бейбит; публичная редакция — «Редакция The Tenge».
